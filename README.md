# Face & Body Sweden

Prototyp för kliniken i Kristianstad. Besökaren väljer behandling, datum och tid, fyller i uppgifter och väljer Swish eller betalning på plats.

Bokningar sparas i webbläsaren. Swish är inte inkopplat, och ingen betalning dras.

```bash
npm install
npm run dev
```

Hero-bilderna byts i `public/hero` och listan i `src/data.ts`.
